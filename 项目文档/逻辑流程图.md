## 八、预约频次限制校验流程

```
┌──────────────────────────┐
│ POST /api/bookings       │
│ 收到预约请求              │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ 校验 1：时段可用性        │
│ time_slot.is_open = true │
│ time_slot.is_booked=false│
└──┬───────────────────┬───┘
   │通过               │不通过
   ▼                   ▼
┌──────────┐    ┌──────────────────┐
│ 继续     │    │ 400: 时段不可用   │
└────┬─────┘    └──────────────────┘
     │
     ▼
┌──────────────────────────┐
│ 校验 2：2周内成功上限     │
│ SELECT COUNT(*) FROM     │
│ bookings WHERE           │
│ team_id = ? AND          │
│ status = 'won' AND       │
│ created_at >= 14天前     │
└──┬───────────────────┬───┘
   │ < 2               │ >= 2
   ▼                   ▼
┌──────────┐    ┌──────────────────────┐
│ 继续     │    │ 400: 2周内已达上限(2次)│
└────┬─────┘    └──────────────────────┘
     │
     ▼
┌──────────────────────────┐
│ 校验 3：30天取消上限      │
│ SELECT COUNT(*) FROM     │
│ cancel_records WHERE     │
│ team_id = ? AND          │
│ cancelled_at >= 30天前   │
└──┬───────────────────┬───┘
   │ < 2               │ >= 2
   ▼                   ▼
┌──────────┐    ┌──────────────────────┐
│ 创建预约 │    │ 400: 30天取消已达上限  │
│ status=  │    └──────────────────────┘
│ pending  │
└──────────┘
```
