### 1.1 你需要准备的东西

| 序号 | 事项                  | 说明                     |
| -- | ------------------- | ---------------------- |
| 1  | 一台电脑（Mac 或 Windows） | 用于操作部署                 |

## 2. 购买云服务器

### 2.1 为什么选择腾讯云轻量应用服务器

- 微信小程序后端必须使用 HTTPS 域名或备案过的 IP
- 腾讯云与微信同属腾讯生态，网络延迟最低
- 轻量应用服务器内置常用镜像，开箱即用
- 价格实惠，最低配置即可满足本项目的需求

### 2.2 购买步骤

**第一步：打开腾讯云官网**

1. 浏览器访问 [cloud.tencent.com](https://cloud.tencent.com/)
2. 点击右上角「免费注册」，用微信扫码完成注册
3. 注册后按提示完成**实名认证**（需要身份证和手机号）

**第二步：购买轻量应用服务器**

1. 访问 [轻量应用服务器购买页](https://buy.cloud.tencent.com/lighthouse)
2. 选择以下配置：

| 配置项 | 推荐选择                             |
| --- | -------------------------------- |
| 地域  | **广州**（离珠海最近，延迟最低）               |
| 镜像  | **Ubuntu 22.04 LTS**             |
| 套餐  | **2核 2GB 内存 50GB SSD**（约 68 元/月） |
| 时长  | 先选 1 个月试用                        |

1. 点击「立即购买」，完成支付

**第三步：获取服务器信息**

购买成功后，进入 [轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse/instance)，你会看到：

- **公网 IP**（例如：`123.456.789.10`） ← 记录下来
- **实例状态**：运行中

**第四步：设置防火墙规则**

1. 在控制台点击你的服务器实例
2. 点击「防火墙」标签页
3. 点击「添加规则」，添加以下规则：

| 端口   | 协议  | 说明              |
| ---- | --- | --------------- |
| 8000 | TCP | 后端 API 服务       |
| 80   | TCP | HTTP（用于后续申请域名）  |
| 443  | TCP | HTTPS（用于后续申请域名） |
| 22   | TCP | SSH 远程连接（默认已开启） |

1. 点击「确定」保存

## 3. 连接服务器

### 3.1 Windows 用户

推荐使用 **FinalShell** 或 **Xshell**：

1. 下载 [FinalShell](http://www.hostbuf.com/t/988.html) 并安装
2. 打开 FinalShell，点击左上角「文件夹」图标 → 「新建连接」
3. 填写以下信息：
   - 名称：珠海艺术中心
   - 主机：你的服务器公网 IP
   - 端口：22
   - 用户名：`root`（腾讯云轻量服务器默认）
   - 密码：在腾讯云控制台，点击服务器实例 → 「重置密码」，设置一个新密码
4. 点击「确定」，双击连接

### 3.2 Mac 用户

Mac 自带「终端」应用，直接使用：

1. 打开「终端」应用（在「启动台」→「其他」文件夹中）
2. 输入以下命令（把 `你的服务器IP` 替换为实际 IP）：

```bash
ssh root@你的服务器IP
```

1. 首次连接会提示确认，输入 `yes` 后回车
2. 输入你在腾讯云控制台设置的密码

> **小提示**：终端中输入密码时不会显示任何字符，这是正常的安全设计。输入完直接按回车即可。

### 3.3 连接成功标志

看到类似以下信息，说明连接成功：

```
Welcome to Ubuntu 22.04 LTS
root@VM-xxx:~#
```

## 4. 部署后端

以下所有命令都在**服务器终端**中执行。

### 4.1 更新系统并安装基础软件

```bash
apt update && apt upgrade -y
apt install -y python3 python3-pip python3-venv nginx curl git
```

### 4.2 创建项目目录

```bash
mkdir -p /opt/doumen-culture
cd /opt/doumen-culture
```

### 4.3 上传后端代码到服务器

**方法一：使用 FinalShell（Windows 推荐）**

FinalShell 自带文件传输功能，在左侧文件浏览器中直接拖拽上传 `Backend` 文件夹到 `/opt/doumen-culture/`。

**方法二：使用 scp 命令（Mac 推荐）**

在你的 **Mac 终端**（不是服务器终端）中执行：

```bash
scp -r /Users/meya/Downloads/珠海艺术中心/Backend root@你的服务器IP:/opt/doumen-culture/
```

> 注意：这个命令在 Mac 本地终端执行，不是在服务器终端。

### 4.4 创建 Python 虚拟环境

回到服务器终端，执行：

```bash
cd /opt/doumen-culture/Backend
python3 -m venv venv
source venv/bin/activate
```

看到终端提示符前面出现 `(venv)` 说明虚拟环境激活成功。

### 4.5 安装 Python 依赖

```bash
pip install -r requirements.txt
```

等待安装完成（约 2-3 分钟）。

### 4.6 配置生产环境变量

```bash
nano .env
```

在打开的编辑器中，用以下内容**完全替换**原有内容：

```
DATABASE_URL=sqlite:///./doumen.db
SECRET_KEY=替换为一串随机字符至少32位
WECHAT_APPID=你的微信小程序AppID
WECHAT_SECRET=你的微信小程序AppSecret
WECHAT_IOS_APPID=MengYanLin.MiniApp
WECHAT_IOS_SECRET=
ADMIN_INIT_USERNAME=superadmin
ADMIN_INIT_PASSWORD=SuperAdmin@2026
ENVIRONMENT=production
```

**逐项填写说明：**

| 变量                    | 填写内容                                                      |
| --------------------- | --------------------------------------------------------- |
| `SECRET_KEY`          | 随机生成一串英文+数字，至少 32 位。例如：`aB3xK9mP2qR7vW1yF6dL0nC8tZ4jH5sX` |
| `WECHAT_APPID`        | 在微信公众平台获取的 AppID                                          |
| `WECHAT_SECRET`       | 在微信公众平台获取的 AppSecret                                      |
| `ADMIN_INIT_PASSWORD` | 管理员初始密码，**建议修改为更复杂的密码**                                   |

> **如何生成随机 SECRET\_KEY**：在终端执行 `python3 -c "import secrets; print(secrets.token_urlsafe(32))"`，复制输出的结果。

填写完成后：

- 按 `Ctrl + O`（字母 O），回车保存
- 按 `Ctrl + X` 退出编辑器

### 4.7 测试启动后端

```bash
cd /opt/doumen-culture/Backend
source venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

看到类似以下输出表示启动成功：

```
INFO:     Started server process
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000
```

此时在浏览器访问 `http://你的服务器IP:8000/api/health`，应该看到：

```json
{"status": "ok", "service": "doumen-culture"}
```

> 验证成功后，在终端按 `Ctrl + C` 停止测试运行。

### 4.8 配置后台运行（systemd 服务）

创建 systemd 服务文件，让后端在服务器重启后自动启动：

```bash
nano /etc/systemd/system/doumen-culture.service
```

粘贴以下内容：

```
[Unit]
Description=珠海艺术中心后端服务
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/doumen-culture/Backend
Environment=PATH=/opt/doumen-culture/Backend/venv/bin
ExecStart=/opt/doumen-culture/Backend/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

保存并退出（`Ctrl + O` → 回车 → `Ctrl + X`）。

启动服务：

```bash
systemctl daemon-reload
systemctl enable doumen-culture
systemctl start doumen-culture
```

检查服务状态：

```bash
systemctl status doumen-culture
```

看到 `active (running)` 表示服务已成功运行。

### 4.9 确认 Nginx 已安装

Nginx 已在 4.1 步骤中安装，确认一下：

```bash
nginx -v
```

看到版本号说明安装成功。Nginx 的详细配置将在下一步「配置域名与 HTTPS」中完成。

## 5. 配置域名与 HTTPS

> **重要**：微信小程序正式上线要求后端必须使用 HTTPS 域名，不能直接用 IP 或 HTTP。本章是上线前的必要步骤。

### 5.1 整体流程概览

域名配置的完整流程如下，预计耗时 **7-20 个工作日**（主要是备案等待）：

```
购买域名 → 实名认证 → ICP 备案 → DNS 解析 → 申请 SSL 证书 → 配置 Nginx HTTPS
```

### 5.2 购买域名

**第一步：在腾讯云购买域名**

1. 访问 [腾讯云域名注册](https://buy.cloud.tencent.com/domain)
2. 在搜索框中输入你想要的域名，比如 `zhuhai-art.cn` 或 `doumen-culture.com`
3. 选择一个未被注册的域名，点击「加入购物车」
4. 点击「立即购买」，完成支付

**域名选择建议：**

| 后缀        | 价格（约）  | 推荐度      |
| --------- | ------ | -------- |
| `.cn`     | 29 元/年 | 推荐，备案速度快 |
| `.com`    | 55 元/年 | 推荐，更通用   |
| `.com.cn` | 30 元/年 | 可选       |

> 选 `.cn` 或 `.com` 都可以，备案流程一样。域名本身不影响微信小程序审核。

### 5.3 域名实名认证

购买完成后，需要完成域名实名认证（否则域名无法使用）：

1. 登录 [腾讯云域名控制台](https://console.cloud.tencent.com/domain)
2. 找到刚购买的域名，状态会显示「未实名认证」
3. 点击域名 → 「实名认证」标签
4. 选择「个人」类型，填写以下信息：
   - 域名所有者：你的真实姓名
   - 证件类型：身份证
   - 证件号码：你的身份证号
5. 上传身份证正面照片
6. 提交审核

> 实名认证通常 **1-3 个工作日** 内完成。审核通过后域名状态变为「正常」。

### 5.4 ICP 备案

**为什么要备案？**

根据国家规定，服务器在国内的网站必须完成 ICP 备案才能使用域名访问。腾讯云在备案通过前会拦截未备案域名的 HTTP/HTTPS 请求。

**备案步骤：**

1. 登录 [腾讯云备案系统](https://console.cloud.tencent.com/beian)
2. 点击「开始备案」
3. 按提示填写以下信息：

| 填写项   | 说明                        |
| ----- | ------------------------- |
| 备案类型  | 首次备案                      |
| 主办者性质 | 个人                        |
| 主办者姓名 | 你的真实姓名                    |
| 证件类型  | 身份证                       |
| 证件号码  | 你的身份证号                    |
| 网站名称  | 珠海艺术中心场地预约                |
| 网站域名  | 你购买的域名（如 `zhuhai-art.cn`） |
| 服务内容  | 其他                        |

1. 上传以下材料：
   - 身份证正反面照片
   - **手持身份证照片**（需清晰看到脸和身份证信息）
   - 《网站备案信息真实性核验单》（系统自动生成，电子签名即可）
2. 提交后，腾讯云会先进行初审（1-2 个工作日）
3. 初审通过后，会收到短信验证码，在备案系统中输入验证码
4. 提交至管局审核

**管局审核时间：**

- 广东省：通常 **7-15 个工作日**
- 其他省份：**10-20 个工作日**

> **备案期间不要闲着**：备案等待期间正好可以用来完成服务器部署、后端测试、小程序开发调试等工作。

**备案通过后：**

你会收到工信部发来的短信通知，内容包括备案号（如「粤ICP备2025XXXXXX号」）。此时域名就可以正常访问了。

### 5.5 DNS 解析（域名绑定服务器 IP）

备案通过后，将域名指向你的服务器：

1. 登录 [腾讯云 DNS 解析控制台](https://console.cloud.tencent.com/cns)
2. 找到你的域名，点击「解析」
3. 点击「添加记录」，添加以下两条记录：

| 主机记录  | 记录类型 | 记录值        | TTL |
| ----- | ---- | ---------- | --- |
| `@`   | A    | 你的服务器公网 IP | 600 |
| `www` | A    | 你的服务器公网 IP | 600 |

- `@` 表示根域名（如 `zhuhai-art.cn`）
- `www` 表示 www 子域名（如 `www.zhuhai-art.cn`）

1. 点击「保存」

> DNS 解析生效通常需要几分钟到几小时。可以在终端执行 `ping 你的域名` 来验证是否已指向你的服务器 IP。

### 5.6 申请 SSL 证书

微信小程序要求 HTTPS，所以需要 SSL 证书。腾讯云提供**免费**的 TrustAsia 证书：

1. 访问 [SSL 证书管理控制台](https://console.cloud.tencent.com/ssl)
2. 点击「申请免费证书」
3. 填写以下信息：

| 填写项  | 说明                      |
| ---- | ----------------------- |
| 证书类型 | 免费版（TrustAsia DV SSL）   |
| 绑定域名 | 你的域名（如 `zhuhai-art.cn`） |
| 备注名  | 珠海艺术中心                  |
| 算法   | RSA                     |
| 验证方式 | DNS 自动验证（推荐）            |

1. 点击「提交申请」
2. 系统会自动验证域名所有权，通常 **几分钟内** 签发完成
3. 证书签发后，点击「下载」→ 选择「Nginx」格式
4. 下载后会得到两个文件：
   - `你的域名.crt`（证书文件）
   - `你的域名.key`（私钥文件）

### 5.7 上传证书到服务器

在 **Mac 终端**（本地电脑）中执行，将证书上传到服务器：

```bash
scp 你的域名.crt root@你的服务器IP:/etc/nginx/ssl/
scp 你的域名.key root@你的服务器IP:/etc/nginx/ssl/
```

如果服务器上还没有 ssl 目录，先在服务器终端创建：

```bash
mkdir -p /etc/nginx/ssl
```

### 5.8 配置 Nginx HTTPS

在服务器终端执行：

```bash
nano /etc/nginx/sites-available/doumen-culture
```

**清空原有内容**，粘贴以下配置（把 `你的域名` 替换为实际域名，如 `zhuhai-art.cn`）：

```
# HTTP 自动跳转到 HTTPS
server {
    listen 80;
    server_name 你的域名 www.你的域名;

    return 301 https://$host$request_uri;
}

# HTTPS 服务
server {
    listen 443 ssl http2;
    server_name 你的域名 www.你的域名;

    # SSL 证书配置
    ssl_certificate     /etc/nginx/ssl/你的域名.crt;
    ssl_certificate_key /etc/nginx/ssl/你的域名.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # 反向代理到后端
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    client_max_body_size 10M;
}
```

保存退出（`Ctrl + O` → 回车 → `Ctrl + X`）。

启用配置并重启 Nginx：

```bash
ln -sf /etc/nginx/sites-available/doumen-culture /etc/nginx/sites-enabled/doumen-culture
nginx -t
systemctl restart nginx
```

`nginx -t` 输出 `syntax is ok` 和 `test is successful` 表示配置正确。

### 5.9 验证 HTTPS 访问

在浏览器中访问：

```
https://你的域名/api/health
```

应该看到：

```json
{"status": "ok", "service": "doumen-culture"}
```

浏览器地址栏左边出现 **小锁图标**，说明 HTTPS 配置成功。

## 6. 配置微信小程序

### 6.1 修改 API 地址

在**本地电脑**上，用文本编辑器打开文件：

```
/Users/meya/Downloads/珠海艺术中心/Miniapp/app.js
```

找到第 7 行：

```javascript
apiBase: 'http://192.168.0.28:8000/api'
```

修改为你的域名地址：

```javascript
apiBase: 'https://你的域名/api'
```

保存文件。

### 6.2 配置小程序服务器域名

> 域名备案通过后，才能配置正式域名。备案期间可先用 IP 测试，在微信开发者工具中勾选「不校验合法域名」。

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 左侧菜单点击「开发」→「开发管理」→「开发设置」
3. 在「服务器域名」区域，点击「开始配置」
4. 填写以下域名：

| 配置项               | 填写内容                  |
| ----------------- | --------------------- |
| request 合法域名      | `https://你的域名`        |
| socket 合法域名       | `wss://你的域名`（如不需要可留空） |
| uploadFile 合法域名   | `https://你的域名`        |
| downloadFile 合法域名 | `https://你的域名`        |

1. 点击「保存并提交」

> **注意**：微信每个月只能修改 5 次服务器域名，请确认无误后再提交。

### 6.3 使用微信开发者工具上传代码

## 9. 常见问题排错

### 9.1 无法连接服务器

**可能原因**：防火墙未开放端口

**解决方法**：

1. 登录腾讯云控制台
2. 进入轻量应用服务器 → 你的实例 → 防火墙
3. 确认端口 8000、22 已添加

### 9.2 后端启动失败

**查看错误日志**：

```bash
journalctl -u doumen-culture -n 50 --no-pager
```

**常见错误**：

- `ModuleNotFoundError`：依赖未安装，执行 `pip install -r requirements.txt`
- `Address already in use`：端口被占用，执行 `killall uvicorn` 后重试
- 数据库错误：删除 `doumen.db` 文件后重启服务（会自动重建）

### 9.3 小程序无法连接后端

**可能原因**：

1. API 地址未修改为服务器 IP
2. 微信开发者工具未勾选「不校验合法域名」
3. 服务器防火墙未开放 8000 端口

**解决方法**：

1. 检查 `app.js` 中 `apiBase` 是否正确
2. 微信开发者工具 → 右上角「详情」→「本地设置」→ 勾选「不校验合法域名」
3. 确认服务器防火墙规则

### 9.4 小程序提示「不在以下 request 合法域名列表中」

**解决方法**：

在微信开发者工具中：

1. 点击右上角「详情」按钮
2. 选择「本地设置」标签
3. 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」

> 这只是开发阶段的临时方案。正式上线前需要在微信公众平台配置正式的服务器域名。

### 9.5 HTTPS 配置后浏览器仍提示不安全

**可能原因**：

1. SSL 证书未正确配置或已过期
2. Nginx 配置中证书路径错误
3. 浏览器缓存了旧的 HTTP 重定向

**解决方法**：

1. 检查证书：`openssl x509 -in /etc/nginx/ssl/你的域名.crt -noout -dates`
2. 检查 Nginx 配置：`nginx -t`
3. 清除浏览器缓存后重试

### 9.6 重启后端服务

如果后端出现问题，执行以下命令重启：

```bash
systemctl restart doumen-culture
systemctl status doumen-culture
```
