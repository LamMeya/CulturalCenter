# 斗门文化中心场地预约系统 — 产品文档

> 版本 1.0 | 2026-08-24

---

## 一、产品概述

斗门文化中心场地预约系统是一个面向珠海斗门地区的文化场馆预约管理平台，覆盖**管理后台（Web）**、**用户端（微信小程序 + iOS App）**三个终端，为文化中心运营方和市民提供完整的场地预约、抽签分配、团队管理一站式解决方案。

### 核心价值

- **公平预约** — 抽签机制确保热门时段公平分配，避免先到先得的不公
- **团队协作** — 以团队为单位预约，契合文化团体（舞蹈团、合唱团等）的实际使用场景
- **三端统一** — 管理后台、小程序、iOS App 共享同一套数据和业务逻辑，体验一致

### 目标用户

| 角色 | 端 | 核心需求 |
|------|-----|---------|
| 市民 / 文艺团体成员 | 小程序、iOS | 浏览场馆、预约时段、查看抽签结果、管理团队 |
| 场馆运营方 | Web 管理后台 | 管理场馆信息、生成时间段、审核预约、抽签分配、发布通知 |

## 三、核心业务规则

### 3.1 预约规则

1. **预约单位** — 以团队为单位预约，个人需先加入团队
2. **时段选择** — 每次最多选择 4 个时间段（上午/下午分开）
3. **抽签机制** — 预约后进入"待抽签"状态，管理员统一抽签分配
4. **频次限制** — 每团队 2 周内成功预约上限 2 次、30 天内取消上限 2 次
5. **取消条件** — 仅本人预约、pending 或 won 状态、预约日期未到期

### 3.2 团队规则

1. **团队上限** — 每团队最多 80 人
2. **角色体系** — 队长（1 人）→ 副队长（最多 4 人）→ 成员
3. **队长权限** — 设置副队长、转让队长、解散团队
4. **成员操作** — 仅可退出团队（队长不能退出，需先转让）

### 3.3 时间段规则

1. **周一闭馆** — 不生成周一的时间段，前端日期选择器自动排除周一
2. **生成规则** — 管理员设置默认时间 + 提前天数，批量生成未来时间段
3. **上午/下午** — 时段按 period 分组，前端分两栏展示

## 四、角色与权限

### 用户端

| 角色 | 权限 |
|------|------|
| 普通用户 | 浏览场馆、加入团队、预约时段、查看预约、取消预约 |
| 团队成员 | 上述权限 + 共享团队预约额度 |
| 副队长 | 无特殊系统权限（预留管理能力） |
| 队长 | 管理团队（设置副队长/转让/解散）、查看团队预约统计 |

### 管理后台

| 角色 | 权限 |
|------|------|
| 超级管理员 | 全部权限（管理后台用户 + 场地 + 时间段 + 预约 + 通知） |
| 管理员 | 场地 + 时间段 + 预约 + 通知管理 |
| 操作员 | 预约查看 + 时间段查看 |

## 五、用户流程

### 5.1 首次使用流程

```
登录/注册 → 创建/加入团队 → 浏览场馆 → 选择日期 → 选择时段 → 确认预约 → 等待抽签 → 查看结果
```

### 5.2 预约流程

```
首页场馆列表 → 点击场馆 → 场馆详情页 → 左右滑动选择日期 → 选择上午/下午时段 → 底部确认 → 成功提示
```

### 5.3 抽签流程（管理员端）

```
查看预约列表 → 按时间段分组 → 选择抽签方式 → 执行抽签 → 中签/未中签状态更新 → 用户端同步
```

## 六、设计理念

### 品牌定位

以"渔乡文艺"为主题，融合珠海斗门的渔村文化元素，打造有温度、有地域特色的文化场馆预约体验。

### 设计关键词

- **青绿**（海洋/自然） — 主色调 `#3d8e7a`
- **渔灯金**（温暖/人文） — 强调色 `#e8a840`
- **贝壳白**（纯粹/宁静） — 背景色 `#faf8f6`
- **波浪纹**（渔村记忆） — 装饰元素
