### 2.2 数据模型

**10 张表：**

| 模型 | 表名 | 核心字段 |
|------|------|---------|
| `AdminUser` | `admin_users` | id, username, password_hash, name, role (super_admin/admin/operator), is_active |
| `User` | `users` | id, nickname, phone, password_hash, openid, unionid, avatar_url, is_active |
| `Team` | `teams` | id, name, intro, leader_user_id, max_members(80), is_active |
| `TeamMember` | `team_members` | id, team_id (FK), user_id (FK), role (leader/vice_leader/member), joined_at |

| `Booking` | `bookings` | id, venue_id, time_slot_id, team_id, user_id, status (pending/won/lost/cancelled), created_at |

| `DrawRecord` | `draw_records` | id, booking_id, slot_id, draw_time, result |
| `CancelRecord` | `cancel_records` | id, booking_id, cancel_reason, cancelled_at, cancelled_by |
| `SystemConfig` | `system_configs` | id, key, value, description |

### 2.4 认证方案

- **管理员** — JWT token，`/api/auth/login` 获取，Authorization Bearer 头携带
- **用户** — 密码登录 `/api/users/login/password` 返回 token，微信登录 `/api/users/login/miniprogram` 通过 code 换 token
- Token 有效期：7 天

## 五、业务关键逻辑

### 5.1 预约频次限制

```python
# 2 周内成功预约上限
success_count_2w = db.query(Booking).filter(
    Booking.team_id == team_id,
    Booking.status == BookingStatus.WON,
    Booking.created_at >= now_cn() - timedelta(days=14)
).count()

# 30 天内取消上限
cancel_count_30d = db.query(CancelRecord).filter(
    CancelRecord.team_id == team_id,
    CancelRecord.cancelled_at >= now_cn() - timedelta(days=30)
).count()
```

### 5.2 预约查询逻辑（小程序）

```
loadBookings()
  ├── 1. GET /api/teams?user_id={userId}     → 获取用户团队
  ├── 2. 有团队 → GET /api/users/{userId}/bookings?team_id={teamId}
  │    无团队 → GET /api/users/{userId}/bookings?user_id={userId}
  └── 3. 处理数据
       ├── time_slot.date   → bookingDate
       ├── time_slot.start  → bookingStart (截取 HH:MM)
       ├── time_slot.end    → bookingEnd (截取 HH:MM)
       ├── globalData.userInfo.nickname → bookerName
       └── canCancel = (status === 'pending' || 'won') && 日期 >= 今天
```

### 5.3 取消预约条件

三个条件同时满足：
1. 本人预约 (`isOwn: true`)
2. 状态为 `pending` 或 `won`
3. 预约日期未到期 (`bookingDate >= todayStr`)

### 5.4 周一排除逻辑

```javascript
// 小程序
const dates = [];
for (let i = 0; i < 14; i++) {
    const d = new Date(today);
    d.setDate(today.getDate() + i);
    if (d.getDay() !== 1) {  // 排除周一
        dates.push(formatDate(d));
    }
}
```

```swift
// iOS
let dates = (0..<14).compactMap { offset in
    let date = Calendar.current.date(byAdding: .day, value: offset, to: today)!
    let weekday = Calendar.current.component(.weekday, from: date)
    return weekday != 2 ? date : nil  // 排除周一 (Sunday=1)
}
```

## 六、部署说明

### 6.1 后端部署

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量 (.env)
DATABASE_URL=sqlite:///./doumen.db  # 或 PostgreSQL
SECRET_KEY=生产环境密钥
ENVIRONMENT=production

# 3. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 4. （可选）使用 systemd 或 supervisor 守护进程
```

### 6.2 小程序部署

1. 在微信开发者工具中打开 `Miniapp/` 目录
2. 修改 `app.js` 中 `apiBase` 为生产环境地址
3. 上传代码 → 提交审核 → 发布

### 6.3 iOS 部署

1. 在 Xcode 中打开 `iOS/MiniApp.xcodeproj`
2. 修改 `APIService.swift` 中 `baseURL` 为生产环境地址
3. 配置微信 Universal Link（生产环境需要）
4. Archive → 上传 App Store Connect

### 6.4 数据库迁移

SQLite → PostgreSQL 迁移：

```bash
# 1. 导出 SQLite 数据
sqlite3 doumen.db .dump > dump.sql

# 2. 修改 DATABASE_URL
DATABASE_URL=postgresql://user:pass@host:5432/doumen

# 3. 重启服务（自动建表，需手动迁移数据）
```
