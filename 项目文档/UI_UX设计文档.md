## 一、设计系统

### 1.1 Design Tokens

| Token | 色值 | 用途 |
|-------|------|------|
| `--dm-primary` | `#3d8e7a` | 主色：导航栏、按钮、选中态、链接 |
| `--dm-primary-dark` | `#2e6e5e` | 主色深色：按钮按下态 |
| `--dm-bg` | `#faf8f6` | 页面背景（贝壳白） |
| `--dm-card` | `#ffffff` | 卡片背景 |
| `--dm-border` | `#ebe3da` | 边框、分割线 |
| `--dm-text` | `#211c18` | 正文字色 |
| `--dm-muted` | `#8c7b6a` | 次要文字、辅助信息 |
| `--dm-accent` | `#e8a840` | 强调色（渔灯金）：通知横幅、标签 |
| `--dm-radius` | `16rpx` | 卡片圆角 |
| `--dm-radius-sm` | `8rpx` | 小圆角：按钮、标签 |

### 1.2 字体

```
系统默认字体栈：
-apple-system, 'PingFang SC', 'Noto Sans SC', sans-serif

字号层级：
- 48rpx — 品牌名称（首页）
- 32rpx — 区块标题
- 30rpx — 主按钮
- 28rpx — 正文、卡片信息
- 26rpx — 辅助文字、通知内容
- 24rpx — 副标题、标签
- 22rpx — 次要内容
```

### 1.3 状态色彩

| 状态 | 背景色 | 文字色 |
|------|--------|--------|
| 待抽签 (pending) | `#fdf6e8` | `#e8a840` |
| 已中签 (won) | `#e8f5ee` | `#3d8e7a` |
| 未中签 (lost) | `#f5f0eb` | `#8c7b6a` |
| 已取消 (cancelled) | `#fdf0ed` | `#d4644a` |

### 1.4 选中态

- 时段选中：背景 `#c8ead5`（浅绿），边框 `#3d8e7a`，文字 `#3d8e7a`
- 时段未选中：背景 `#ffffff`，边框 `#ebe3da`，文字 `#211c18`

## 二、交互模式

### 2.1 底部弹窗 Sheet

用于"创建团队"和"加入团队"操作，从底部滑出半屏面板：

- 顶部圆角手柄（`sheet-handle`）
- 标题栏（标题 + ✕ 关闭）
- 内容区（表单 / 列表）
- 底部确认按钮
- 点击蒙层关闭

### 2.2 模态弹窗 Modal

用于确认操作（解散团队、退出团队、转让队长、设置副队长）：

- 居中弹出
- 标题 + 描述
- 操作列表 / 选择列表
- 取消 + 确认双按钮

### 2.3 通知横幅

首页顶部横向滚动通知：

- 左侧铃铛图标固定
- 中间 swiper 垂直滚动（3s 间隔）
- 右侧箭头入口
- 双行显示：title（28rpx 加粗）+ content（22rpx 浅色）

### 2.4 日期横向滚动

场馆详情页 14 天日期选择器：

- `scroll-view` 横向滚动
- 自动排除周一（`getDay() !== 1`）
- 选中态：青绿圆角背景 + 白色文字
- 未选中：灰色文字

### 2.5 时段选择网格

- 上午/下午分两栏，各自 `flex-wrap: wrap` 网格
- 多项选择（最多 4 个），互不排斥
- 已选时段底部摘要栏，水平滚动展示

### 2.6 波浪装饰动画

首页品牌区和团队空状态使用三层波浪装饰：

- 三层半透明条纹（`rgba(255,255,255,0.15/0.10/0.05)`）
- 各自以不同速度左右浮动（6s / 8s / 10s）
- 使用 `repeating-linear-gradient` 实现条纹纹理
- 团队空状态版本使用主色半透明（`rgba(61,142,122,0.08/0.05/0.03)`）

## 四、响应式适配

### 小程序

- 使用 `rpx` 单位，自动适配不同屏幕宽度
- 卡片固定 `margin: 16rpx 24rpx`
- 时段项 `flex-wrap: wrap`，每行 3 个

### iOS

- SwiftUI 原生布局，自动适配 iPhone 全系列
- 场馆卡片使用 `LazyVGrid` 两列网格
- 时段选择使用 `LazyVGrid` 三列网格

## 五、空状态与错误处理

| 场景 | 处理方式 |
|------|---------|
| 无团队 | 波浪装饰空状态 + 创建/加入按钮 |
| 无场馆 | 加载骨架屏 → 空状态提示 |
| 无预约 | "暂无预约记录"空状态 |
| 无通知 | 隐藏通知横幅 |
| 网络错误 | 错误提示 + 重试按钮 |
| 预约失败 | 显示后端返回的具体原因（如"2周内已达上限"） |
| 登录过期 | 自动跳转登录页 |

## 六、动效规范

| 动效 | 场景 | 参数 |
|------|------|------|
| 波浪浮动 | 品牌区装饰 | `ease-in-out`，6s/8s/10s 循环 |
| 加载旋转 | 数据加载中 | `linear`，0.8s 无限旋转 |
| 弹窗滑入 | Sheet 底部弹窗 | `translateY` 过渡 |
| 通知滚动 | 首页通知横幅 | swiper 垂直滚动，3s 间隔 |
| 按钮按下 | 所有按钮 | `:active` 缩放 + 颜色变化 |
| 统计展开 | 预约统计详情 | 箭头旋转 180° |

---

## 七、无障碍

- 所有可点击元素有 `:active` 按下反馈
- 状态标签使用颜色 + 文字双重标识
- 弹窗蒙层可点击关闭
- 输入框有 `placeholder` 提示
- 错误信息直接展示具体原因，不使用通用文案
